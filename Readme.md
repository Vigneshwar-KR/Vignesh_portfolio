## Contact form

GitHub Pages is a static hosting service and cannot execute the PHP handler in
`forms/contact.php`. When the site is opened on GitHub Pages, the contact form
opens the visitor's email application using the address configured in the
form's `data-static-email` attribute. The PHP handler remains available for
deployments on a PHP-enabled web server.
